# User Guide

## Getting Started

1. Navigate to the CAC Portal URL
2. Login with your credentials
3. You'll land on the Dashboard showing key metrics

## Member Management

- **View Members**: Go to Members → see all CAC members with status badges
- **Add Member**: Click "Add Member" (Chair/Admin only) → fill in the form
- **View Profile**: Click any member name to see their full profile

## Meeting Management

- **View Meetings**: Go to Meetings → filter by status
- **Schedule Meeting**: Click "Schedule Meeting" → fill title, date, location, agenda
- **View Details**: Click any meeting to see agenda, minutes, and attendance
- **Record Attendance**: In meeting detail (Admin/Chair), mark members present/absent

## Document Library

- **Browse Documents**: Filter by type (Agenda, Minutes, Report, etc.)
- **Upload Document**: Click "Upload" → provide title, type, and optional file
- **Download**: Click any document to download

## Surveys

- **Create Survey**: Click "New Survey" → add title and questions
- **Respond**: Active surveys show a response form
- **View Results**: Click "Results" on any survey

## Voting

- **View Votes**: See all open and closed votes
- **Cast Vote**: Open votes show voting options → select and submit
- **Create Vote**: Chair/Admin can create new votes with custom options

## Decisions

- **View Decisions**: Browse all CAC decisions with status and priority
- **Create Decision**: Chair/Admin can create new decisions
- **Track Status**: Update decision status as it progresses

## Reports

- View key performance indicators (KPIs)
- Charts for member distribution, meeting status, decision tracking
- Summary table with all metrics
